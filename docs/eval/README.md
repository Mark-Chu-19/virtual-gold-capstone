# Evaluation reports

Results of running the service, or parts of it, on the evaluation dataset (`data/`). Literature and design questions go in `docs/research/`; the scripts that produce these numbers live with the code in `service/scripts/eval/`.

Layout: `docs/eval/<date>/<file>`, where the date is the day of the run. Each report names the dataset split, the branch and commit, and the tier table version it used.

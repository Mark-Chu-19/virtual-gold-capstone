1Research based on the project description

The brief asks for a hybrid assistant that escalates to the cloud "when additional confidence or reasoning capability is required". We researched what that confidence signal can be on an 8B local model, and what it costs.

Confidence signal
Two signals work on an 8B model at near-zero cost per query: the token log-probability the model already produces, and a Semantic Entropy Probe trained once on the model's hidden states. Both have published evidence at 7–8B scale.
Excluded
Asking the model how confident it is does not work at this size. Across seven 3–9B open-weight models, 91.7% of answers claimed at least 95% confidence whether right or wrong. We will not route on self-reported confidence.
Local models
Llama 3.1 8B as the primary model, Qwen3 8B as the secondary for code and multilingual queries, run with Hugging Face transformers at 4-bit so the harness can read log-probs and hidden states. Qwen3 carries source, hash and licence checks.
Benchmarks
MMLU subset and GSM8K first, as the general-purpose benchmarks you asked for on Sep 3; TruthfulQA and HaluEval for factuality; Presidio's evaluation module and a labelled prompt-injection set for security.

2Architecture v0.3

Local first. The confidence score decides whether escalation is needed; the sensitivity class decides whether it is allowed. When both say no, the system admits uncertainty rather than sending confidential data out.

Request flow: three decision points
De-identification round trip
What is in the prototype
  • One trust boundary. Only the router talks to the cloud, and only with redacted, minimized content. The sandbox enforces this with a private network and an egress proxy that logs every request.
  • De-identification round trip. Presidio replaces names, accounts and amounts with placeholders before any cloud call; the placeholder table never leaves the sandbox; the reply is mapped back before the user sees it.
  • Data sensitivity classification. Three levels by default: public, internal, confidential. Confidential requests stay local no matter how low the confidence.
  • Replaceable components. Models, cloud provider and vector store sit behind interfaces; swapping Qwen3 out is a configuration change.
  • Interface. CLI and REST API only, no GUI, as agreed on Sep 3.
  • Deferred. A document knowledge base (RAG) is a stretch goal; we revisit after the midpoint once a sector and sample formats are set.

3Comparison: how we will show the trade-off

The same test set runs under three configurations. That is the only way to answer your two questions from Sep 3: how big is the gap to the cloud, and what does the local path save.

ConfigurationWhat it isWhat it tells us
Local-onlyEvery request answered by the 8B model, no escalationQuality floor, cost floor, privacy ceiling
HybridLocal first; confidence and sensitivity decide escalationWhere our proposal lands between the two extremes
Cloud-onlyEvery request straight to the cloud modelQuality ceiling, cost ceiling, privacy floor

Six metrics per configuration: accuracy · latency · cost per query · escalation rate · PII-leak rate · prompt-injection resistance.

What you will see at the midpoint (Oct 2–9, week 7)

Three configurations, side by side
Local-only, hybrid and cloud-only, each run on the same MMLU subset and GSM8K questions, so the gap between the 8B model and the cloud model is measured on identical inputs.
Four numbers per configuration
Accuracy, escalation rate, cost per query and latency. PII-leak rate and prompt-injection resistance follow in weeks 9–11 once the security tests are built.
One chart
Escalation rate against accuracy for the hybrid configuration, which answers "how much escalation is enough" and where the cost-quality trade-off sits.
One live demo
A request containing PII goes through redaction, escalation and re-identification in the CLI, end to end, so the privacy path is shown working rather than described.
After the midpoint, weeks 9–11
The remaining confidence signals, the two security metrics, and hardware scenarios (CPU, T4, A10G, 4-bit vs 8-bit), so the final report can state what on-premises hardware buys how much less cloud traffic.
